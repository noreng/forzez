# Art-brand naming — status (2026-10-13)

## DECIDED: Forzez — forzez.com
- Say it like "forces". Truzme's sibling: truss → Truzme, forces → Forzez.
- Web search clean (only a GitHub user "forzez"). forzes.com and similar are taken — always write it with z.
- Two z's = two triangle elements for the logo.
- To do: TMview + USPTO (classes 16, 41), social handles @forzez, "say it and have them write it" test.

## DECIDED: colour convention — Compression = Red, Tension = Blue (2026-10-13)
- Matches Bridge Designer (ex West Point Bridge Designer), what most students/teachers know. Some users found the old Truzme convention (tension red) odd.
- **Truzme:** default = compression red / tension blue. Add a setting (teacher/project level, travels with the shared link/model) for the FEA convention (tension red) + optional colour-blind palette (e.g. orange/blue). Legend always visible, also on exports.
- **Forzez:** fixed palette, no toggle (art brand). Same as Truzme's default, so both brands speak one language. Legend/title block on the piece.

## Previous favourites and why they fell
- Formzart — another artist found on Google with the same name.
- Formz (as product name) / formz.art — formZ is AutoDesSys' architecture 3D software (formz.com).
- Forzme — reads "force me" (coercive connotation).

## Other candidates still clean (backup)
- Avawerk, Arcograph (.studio), Truzwerk, Forzpen, Loomwerk, Gramwerk.

## Rejected (and why)
- Truzart, Struzart/Strutzart, Statink, Truzink, Zugo, Equilo, Culmo — taken.
- Forzart — NSFW artist; Forziart — one letter from it.
- Forzaart — Microsoft Forza.
- Struart — StruArt (Hugh Morrison, structural engineering education).
- Structart — .com $10k.
- Vawart — VAW = Violence Against Women.
- Momwart — reads "mom wart".
- Girafika, Grafme, Grafinka — existing shops/sites.
- Truz- prefix generally: TRUZ is a LINE Friends character with merch (class 16 risk).

## Brand model notes
- Separate brand from Truzme; one-way link "Powered by Truzme" (Truzme stays school-safe, no shop links).
- Two tiers: plotted Originals (family-plotted, signed, numbered) + print-on-demand Prints (Prodigi/Gelato).

## The Forze Code
Every piece carries a short code (e.g. `FZ-3K9X-2A`) that encodes the exact structure.
Type or scan it at forzez.com/code to open the model, watch it being drawn, or remix it.
- "Every Forzez has a Forze Code."
- "Crack the Forze Code."
- Kids version: "The Forze Code is the secret recipe for your bridge."
(Technically: the compressed model hash / content-addressed ID.)
